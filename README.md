# Vrinda-Store-Data-Analysis
OBJECTIVE:- Vrinda store wants to create an annual sales report . so that Vrinda can understand their customer and grow more.
In this project i have analyzed following facts:
a)Order vs Sales per months
b)Top states according to sales
c)Orders in respect to age and gender
d)Orders through channels
e)Sales by men and women
f)Order status that is how many product is returned ,refunded etc.
